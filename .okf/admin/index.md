# Admin

Active Admin is the internal operations interface. It is mounted from `app/admin/` and secured by the [admin user](/shared/admin-user.md) Devise account.

- [Active Admin configuration](active-admin-configuration.md) - global settings, authentication, and the dashboard
- [Instagram profiles admin](instagram-profiles-admin.md) - profile listing, filters, bulk and member actions
- [TikTok profiles admin](tiktok-profiles-admin.md) - TikTok profile listing and the post refresh action
- [Supporting admin resources](supporting-admin-resources.md) - Instagram and TikTok posts, tags, and admin users
