- [Instagram profiles controller](instagram-profiles-controller.md) - Profile listings and profile detail pages
- [TikTok profiles controller](tiktok-profiles-controller.md) - TikTok profile listings and detail pages
- [Posts controller](posts-controller.md) - Daily top-post lists for Instagram
- [Tags controller](tags-controller.md) - Tag index and tag detail pages
- [Category controller](category-controller.md) - Profiles filtered by profile type
- [Home controller](home-controller.md) - Homepage and the deploy endpoint
- [Pages controller](pages-controller.md) - About page
- [Legal controller](legal-controller.md) - Privacy and terms pages
- [Errors controller](errors-controller.md) - Error pages for not-found, unprocessable, and server errors
- [Blob files controller](blob-files-controller.md) - Serves Active Storage files from the local disk
- [SEO concern](seo-concern.md) - Shared meta-tag helpers mixed into page controllers
